# Kindle/Ebook連続スクリーンショット・ページめくりスクリプト

## 概要

`ScreenShot.py` は、指定したウィンドウ（デフォルトはKindle）のスクリーンショットを連続して撮影し、自動でページをめくるPythonスクリプトです。
電子書籍の特定ページ範囲を画像として保存したい場合などに便利です。

## 特徴

*   **対象ウィンドウ指定**: ウィンドウタイトルの一部を指定して、操作対象のアプリケーションを選択できます。
*   **自動ページめくり**: 指定した矢印キー（左 `left` または 右 `right`）で自動的にページをめくります。
*   **連続スクリーンショット**: 指定した枚数だけ、ウィンドウ全体をキャプチャします。
*   **カスタマイズ可能**: ページめくり方向、撮影枚数、ページめくり後の待機時間、保存先フォルダをコマンドライン引数で設定できます。

## 要件

*   Python 3.x
*   以下のPythonライブラリ:
    *   `pyautogui`
    *   `pygetwindow`

## インストール

1.  **Pythonのインストール**: まだPythonがインストールされていない場合は、[Python公式サイト](https://www.python.org/)からダウンロードしてインストールしてください。
2.  **リポジトリのクローン（任意）**: または、`ScreenShot.py` ファイルを直接ダウンロードします。
    ```bash
    git clone <リポジトリURL> # もしあれば
    cd <リポジトリディレクトリ>
    ```
3.  **必要なライブラリのインストール**: ターミナルまたはコマンドプロンプトを開き、`requirements.txt` ファイルがあるディレクトリで以下のコマンドを実行します。
    ```bash
    pip install -r requirements.txt
    ```
    (または、個別にインストールする場合: `pip install pyautogui pygetwindow`)

## 使い方

ターミナルまたはコマンドプロンプトから以下のようにスクリプトを実行します。

```bash
python ScreenShot.py [オプション]
```

### オプション

| オプション        | 説明                                                         |
|-------------------|--------------------------------------------------------------|
| `--direction`     | ページめくりに使用する矢印キー (`left` または `right`)。デフォルト: `left` |
| `--title`         | 対象ウィンドウのタイトルに含まれる文字列。デフォルト: `Kindle` |
| `--count`         | 撮影するスクリーンショットの枚数。デフォルト: `10`           |
| `--delay`         | ページめくり後の待機時間（秒）。デフォルト: `1.0`           |
| `--output`        | スクリーンショットの保存先フォルダ名。デフォルト: `screenshots`|

### 実行例

**例1: Kindleウィンドウで右矢印キーで50ページ分撮影（待機時間1.5秒）**

```bash
python ScreenShot.py --title Kindle --direction right --count 50 --delay 1.5
```

**例2: "My Reader App" というタイトルのウィンドウで左矢印キーで20ページ分撮影し、`ebook_captures` フォルダに保存**

```bash
python ScreenShot.py --title "My Reader App" --direction left --count 20 --output ebook_captures
```

### 実行の流れ

1.  スクリプトは指定されたタイトルのウィンドウを探します。
2.  見つかると、5秒間の待機時間があります。（この間にキャプチャしたいページを開いてください）
3.  指定された回数、以下の処理を繰り返します:
    *   現在のウィンドウ表示領域のスクリーンショットを撮影し、指定フォルダに `page_XXX.png` として保存します。
    *   指定された矢印キーを押してページをめくります。
    *   指定された時間待機します。
4.  処理が完了するか、`Ctrl+C` で中断されると終了します。

## 注意事項

*   **ウィンドウのアクティブ化**: スクリプト開始前に、対象のウィンドウをクリックするなどしてアクティブにしておくことを推奨します。ページめくりが機能しない場合は、これが原因の可能性があります。
*   **実行中の操作**: スクリプト実行中は、マウスやキーボードの操作を行わないでください。意図しない動作を引き起こす可能性があります。
*   **macOS**: 高解像度ディスプレイ (Retinaなど) を使用している場合、スクリーンショットの範囲がずれることがあります。
*   **ウィンドウ検出**: `--title` で指定する文字列は、対象ウィンドウのタイトルバーに表示されている文字列の一部と一致する必要があります。
