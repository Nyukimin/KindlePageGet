# Kindle/Ebook連続スクリーンショット・ページめくりスクリプト

このリポジトリには、以下の2つの独立したPythonスクリプトが含まれています。

1.  **`ScreenShot.py`**: 指定したウィンドウのスクリーンショットを連続撮影し、ページ送りを行うスクリプト。
2.  **`PdfMaker.py`**: 指定フォルダ内の連番PNGファイルを結合してPDFを作成するスクリプト。

---

## ScreenShot.py: 連続スクリーンショット＆ページめくり

### 概要

`ScreenShot.py` は、指定したウィンドウ（デフォルトはKindle）のスクリーンショットを連続して撮影し、自動でページをめくるPythonスクリプトです。
電子書籍の特定ページ範囲を画像として保存したい場合などに便利です。

### 特徴

*   **対象ウィンドウ指定**: ウィンドウタイトルの一部を指定して、操作対象のアプリケーションを選択できます。
*   **自動ページめくり**: 指定した矢印キー（`left`, `right`, `up`, `down`）で自動的にページをめくります。
*   **連続スクリーンショット**: 指定した枚数だけ、ウィンドウ全体をキャプチャします。
*   **カスタマイズ可能**: ページめくり方向、撮影枚数、待機時間、保存先フォルダをコマンドライン引数で設定できます。

### 要件

*   Python 3.x
*   以下のPythonライブラリ (詳細は `requirements.txt` 参照):
    *   `pyautogui`
    *   `pygetwindow`

### インストール

1.  **Pythonのインストール**: まだPythonがインストールされていない場合は、[Python公式サイト](https://www.python.org/)からダウンロードしてインストールしてください。
2.  **リポジトリのクローン/ダウンロード**: `ScreenShot.py` と `requirements.txt` を取得します。
3.  **必要なライブラリのインストール**: `requirements.txt` を使用してインストールします。
    ```bash
    pip install -r requirements.txt
    ```
    (必要なのは `pyautogui` と `pygetwindow` のみです)

### 使い方 (`ScreenShot.py`)

```bash
python ScreenShot.py [オプション]
```

**オプション:**

| オプション        | 説明                                                                     |
|-------------------|--------------------------------------------------------------------------|
| `--direction`     | ページめくりに使用する矢印キー (`left`, `right`, `up`, `down`)。デフォルト: `left` |
| `--title`         | 対象ウィンドウのタイトルに含まれる文字列。デフォルト: `Kindle`             |
| `--count`         | 撮影するスクリーンショットの枚数。デフォルト: `10`                       |
| `--delay`         | ページめくり後の待機時間（秒）。デフォルト: `1.0`                       |
| `--output`        | スクリーンショットの保存先フォルダ名。デフォルト: `screenshots`         |

**実行例:**

```bash
# Kindleウィンドウで右矢印キーで50ページ分撮影（待機時間1.5秒）
python ScreenShot.py --title Kindle --direction right --count 50 --delay 1.5

# "My Reader App" というタイトルで左矢印キーで20ページ分撮影し、`ebook_captures` フォルダに保存
python ScreenShot.py --title "My Reader App" --direction left --count 20 --output ebook_captures
```

**実行の流れ:**

1.  指定されたタイトルのウィンドウを探します。
2.  5秒待機します。
3.  指定回数、スクリーンショット撮影 -> ページめくり -> 待機 を繰り返します。
4.  完了または中断で終了します。

### 注意事項 (`ScreenShot.py`)

*   **ウィンドウのアクティブ化**: スクリプト開始前に、対象のウィンドウをクリックするなどしてアクティブにしておくことを推奨します。ページめくりが機能しない場合は、これが原因の可能性があります。
*   **実行中の操作**: スクリプト実行中は、マウスやキーボードの操作を行わないでください。意図しない動作を引き起こす可能性があります。
*   **macOS**: 高解像度ディスプレイ (Retinaなど) を使用している場合、スクリーンショットの範囲がずれることがあります。
*   **ウィンドウ検出**: `--title` で指定する文字列は、対象ウィンドウのタイトルバーに表示されている文字列の一部と一致する必要があります。

## PdfMaker.py: PNGからPDFを作成

### 概要

`PdfMaker.py` は、特定のフォルダ内にある `page_XXX.png` のような連番形式のPNGファイルを検索し、指定された範囲のファイルを結合して単一のPDFファイルを作成するコマンドラインツールです。
`ScreenShot.py` で作成した画像などをまとめるのに使用できます。

### 特徴

*   **フォルダ指定**: PNGファイルが含まれるフォルダを指定します。
*   **範囲指定**: PDFに含めるファイルの開始番号と枚数を指定できます。
*   **ファイル名指定**: 出力するPDFファイルの名前を指定できます。
*   **自然順ソート**: `page_1.png`, `page_2.png`, ..., `page_10.png` のようにファイル名を正しくソートして結合します。

### 要件

*   Python 3.x
*   以下のPythonライブラリ (詳細は `requirements.txt` 参照):
    *   `img2pdf`
    *   `Pillow` (img2pdfの依存関係)

### インストール

1.  **Pythonのインストール**: まだPythonがインストールされていない場合は、[Python公式サイト](https://www.python.org/)からダウンロードしてインストールしてください。
2.  **リポジトリのクローン/ダウンロード**: `PdfMaker.py` と `requirements.txt` を取得します。
3.  **必要なライブラリのインストール**: `requirements.txt` を使用してインストールします。
    ```bash
    pip install -r requirements.txt
    ```
    (必要なのは `img2pdf` と `Pillow` です)

### 使い方 (`PdfMaker.py`)

```bash
python PdfMaker.py --input <入力フォルダ> [オプション]
```

**オプション:**

| オプション        | 短縮形 | 説明                                                            |
|-------------------|--------|-----------------------------------------------------------------|
| `--input`         | `-i`   | **(必須)** 入力PNGファイル (`page_*.png`) が含まれるフォルダ。     |
| `--output`        | `-o`   | 出力するPDFのファイルパス。デフォルト: `output.pdf`               |
| `--start`         |        | PDFに含める最初のPNGファイルの番号 (1始まり)。デフォルト: `1`     |
| `--count`         |        | PDFに含めるPNGファイルの枚数。デフォルト: `10`                 |

**実行例:**

```bash
# screenshots フォルダ内の page_*.png からデフォルト設定 (1番目から10枚) で output.pdf を作成
python PdfMaker.py --input screenshots

# my_captures フォルダ内の page_*.png のうち、6番目から20枚を my_document.pdf として作成
python PdfMaker.py -i my_captures -o my_document.pdf --start 6 --count 20
```

### 注意事項 (`PdfMaker.py`)

*   **入力ファイル形式**: このスクリプトは、入力フォルダ内に `page_` で始まり、数値が続き、`.png` で終わるファイルが存在することを期待しています。
*   **アルファチャンネル**: 透過情報 (アルファチャンネル) を持つPNGファイルは、`img2pdf` の制限によりエラーとなる可能性があります。
